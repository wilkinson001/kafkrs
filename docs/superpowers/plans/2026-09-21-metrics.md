# Broker Metrics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Prometheus scrape endpoint exposing 32 broker metrics across produce, fetch, uploader, retention, partition state, runtime, and wire subsystems, using the `metrics` crate façade so the exporter can be swapped for native OTLP later without touching call sites. Bundle in a breaking restructure of `Config.ports: Vec<u16>` into a typed `[ports]` section.

**Architecture:** One new module (`kafkrs-server/src/metrics.rs`) installs the global Prometheus recorder + admin HTTP listener at boot when `ports.metrics` is set. Call-site instrumentation uses `metrics::counter!`/`gauge!`/`histogram!` macros throughout the broker; when no port is configured, `metrics::init` returns without installing a recorder and every call-site macro becomes a nanoseconds-cost noop through the crate's default recorder.

**Tech Stack:** Rust with `metrics = "0.24"` (façade) and `metrics-exporter-prometheus = "0.16"` (Prometheus scrape endpoint). No changes to tokio/prost/existing dependencies.

**Spec:** `docs/superpowers/specs/2026-09-21-metrics-design.md`

## Global Constraints

- **Version target:** 0.5.0 (all three crates in lockstep). Breaking config schema + new bound port justify the minor bump.
- **Wire protocol version:** unchanged at 1. No proto changes.
- **Metric naming:** `messaging.kafkrs.*` for producer/consumer-facing metrics (OTel `messaging.*` semantic convention); `kafkrs.*` for broker-internal state. Dots become underscores in the Prometheus exposition format.
- **Cardinality policy:** every hot-path metric emits `topic`. `partition` is added only when `broker.metrics_high_cardinality = true` at boot. Broker-wide metrics (`kafkrs.runtime.*`, `kafkrs.wire.connections_*`, `kafkrs.retention.sweep_kicks_*`, `kafkrs.partition.count`) never carry topic or partition labels.
- **Off by default:** `ports.metrics` is `Option<u16>`. When unset, no port is bound and no global recorder is installed.
- **Latency histograms** use one shared bucket set: `[0.5, 1.0, 2.5, 5.0, 10.0, 25.0, 50.0, 100.0, 250.0, 500.0, 1000.0, 5000.0]` (milliseconds).
- **No `.await` on the recorder path.** All `metrics::*` macros are synchronous and lock-free.
- **HIGH_CARDINALITY flag** is set once at `metrics::init` and read-only thereafter.
- **Metric names and label keys are `pub const` items in `kafkrs-server/src/metrics.rs`.** Call sites reference the constants (`counter!(PRODUCE_RECORDS, LABEL_TOPIC => topic.clone())`), never string literals. Rationale: one-edit renames on any future major-version prefix change, compile-time typo detection, and a single canonical catalogue.
- **All 32 metric describes live in `describe_all()` in Task 3**, even for metrics that are only emitted in later tasks. Later tasks add call sites only; they do not add new describes.
- **Commits per task** by the executing subagent are approved for this run; no `Co-Authored-By` trailer.

/// Return a label set for a hot-path metric. Always includes `topic`;
/// includes `partition` only when `metrics_high_cardinality` was true
/// at `init` time.
pub fn partition_label(topic: &str, partition: u32) -> Vec<(&'static str, String)> {

Extend `init` to set the start time, emit `build_info` once, and spawn the uptime updater when the exporter is installed. The updater task is only spawned when metrics is actually enabled (i.e., after `install()?`):

```rust
pub fn init(ports: &PortsConfig, high_cardinality: bool) -> anyhow::Result<()> {
    HIGH_CARDINALITY.store(high_cardinality, Ordering::Relaxed);
    let Some(port) = ports.metrics else {
        return Ok(());
    };
    use metrics_exporter_prometheus::PrometheusBuilder;
    use std::net::SocketAddr;

    let addr: SocketAddr = ([0, 0, 0, 0], port).into();
    PrometheusBuilder::new()
        .set_buckets(LATENCY_BUCKETS_MS)?
        .with_http_listener(addr)
        .install()?;
    START_TIME.set(Instant::now()).ok();
    describe_all();
    emit_build_info();
    tokio::spawn(uptime_updater());
    Ok(())
}

fn emit_build_info() {
    let version = env!("CARGO_PKG_VERSION");
    let git_sha = option_env!("KAFKRS_GIT_SHA").unwrap_or("unknown");
    metrics::gauge!(
        RUNTIME_BUILD_INFO,
        LABEL_VERSION => version,
        LABEL_GIT_SHA => git_sha
    )
    .set(1.0);
}

async fn uptime_updater() {
    let mut ticker = tokio::time::interval(std::time::Duration::from_secs(10));
    loop {
        ticker.tick().await;
        if let Some(start) = START_TIME.get() {
            let uptime = start.elapsed().as_secs_f64();
            metrics::gauge!(RUNTIME_UPTIME_SECONDS).set(uptime);
        }
    }
}
```

`KAFKRS_GIT_SHA` is an optional compile-time env var. If unset (typical local dev), `git_sha` label is `"unknown"`. CI can set it via `KAFKRS_GIT_SHA=$(git rev-parse HEAD) cargo build`.
